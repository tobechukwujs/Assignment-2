
A simple Node.js server that serves my personal website with information about backend development.

Author
Tobechukwu Egboh

How to Run the Server

Install dependencies:
npm install

Create a .env file in the root directory:
PORT=3000

Start the server:
npm start

Open your browser and visit:
http://localhost:3000

## Features
- Home page with introduction
- About page explaining backend development
- Contact page with email and GitHub link
- Custom CSS styling
- 404 error handling
Steps to set up:

Create the folder structure
Copy all the code into respective files
Run npm install to install dotenv
Run npm start to start the server
Visit http://localhost:3000 in your browser
